# LFP Монитор

Приложение и виджет рабочего стола для BMS JK (протокол JK02_32S, прошивки V11 и новее).
Проверялось под плату JK-B1A8S20P, железо V19H, прошивка V19.25.

Что показывает: процент заряда, напряжение, ток (плюс — заряд, минус — разряд),
самую высокую и самую низкую ячейку, температуру. На главном экране ещё
остаток и ёмкость, мощность, температура MOS и все ячейки.

## Как получить APK

1. Распакуйте архив на компьютере.
2. Откройте свой репозиторий на GitHub → **Add file** → **Upload files**.
3. Перетащите в окно **всё содержимое** папки `lfp-monitor`, вместе с папкой `.github`.
   Внизу нажмите **Commit changes**.
4. Откройте вкладку **Actions**. Сборка запустится сама и займёт 5–10 минут.
   Зелёная галочка значит, что всё собралось.
5. На телефоне откройте репозиторий → справа **Releases** → последняя сборка →
   скачайте файл `LfpMonitor-….apk` и установите (браузеру нужно разрешить установку приложений).

Если папка `.github` не загрузилась (во вкладке Actions пусто), создайте файл вручную:
**Add file → Create new file**, имя `.github/workflows/build.yml`, и вставьте туда
содержимое этого файла из архива.

Если сборка завершилась красным крестиком: откройте её, нажмите на шаг с ошибкой,
скопируйте последние строки и пришлите в чат.

## Первый запуск

1. Разрешите доступ к устройствам поблизости и уведомления.
2. **Закройте фирменное приложение** (иначе плата не видна в поиске).
3. Нажмите **Выбрать BMS** и выберите свою плату из списка.
4. Нажмите **Разрешить работу в фоне без ограничений**.
5. Добавьте виджет: долгое нажатие на рабочий стол → Виджеты → LFP Монитор → «Батарея».

На Xiaomi/Redmi дополнительно: Настройки → Приложения → LFP Монитор →
**Автозапуск: включить**, **Контроль активности: нет ограничений**.

## Фирменное приложение

Плата JK принимает только одно Bluetooth-подключение. Когда нужно открыть
фирменное приложение (поменять настройки), нажмите в уведомлении или на главном
экране **«Отпустить на 10 минут»**. Через 10 минут связь вернётся сама,
или нажмите «Подключиться сейчас».

## Отладка

Если цифры не совпадают с фирменным приложением, нажмите
**Скопировать данные для отладки** и вставьте текст в чат.

## Подпись

Файл `app/signing.jks` — общий ключ, чтобы новые версии ставились поверх старой.
Для публикации в Google Play нужно будет сделать свой закрытый ключ.
